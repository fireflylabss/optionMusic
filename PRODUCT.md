# Product

## Register

brand

## Platform

web

## Users

Primary audience: people who keep a local music library and want to play it from the terminal. They own their files and want a compact player with keyboard controls.

The site introduces `still` / `msc` and its interactive TUI to both new listeners and existing CLI users.

## Product Purpose

still music (*still*) is a minimal black-and-white CLI/TUI music player powered by MPV. The site should show how it plays and manages local music, then make installation and help easy to find.

## Positioning

Local music, without the noise — only what matters.

Features to demonstrate: local playlists and M3U, optional yt-dlp downloads, equalizer presets, lyrics and library browsing. Use the current CLI/TUI and README as the source for examples.

## Conversion & proof

- Primary CTA: install still, with AUR and Cargo instructions.
- Secondary CTA: read the documentation or open the GitHub repository.
- The line a visitor remembers after 10 seconds: **Música local, sem ruído — só o essencial.**
- Show the terminal player, explain the local-library workflow, then provide install and help links.
- Proof on hand: the CLI/TUI itself, source on GitHub and Arch/AUR packaging. There are no testimonials or press assets yet.

## Brand Personality

Quiet, exacting, exclusive. Apple-like restraint without copying Apple: black-and-white discipline, generous space, one idea per fold. Emotions: calm confidence, ownership, clarity — never hype.

## Anti-references

- Spotify / Apple Music / streaming discovery UIs
- Generic SaaS landings (purple gradients, feature-card grids, “trusted by”)
- Terminal-core / hacker cosplay (mono-only, ASCII-as-brand)
- Generic “premium” with glow, glass stacks, and decorative excess

## Design Principles

1. **Show the power, don’t pitch features** — the page is a thesis about local listening, not a checklist.
2. **One idea per viewport** — Apple-paced scrolls; never crowded folds.
3. **Quiet exclusivity** — premium through restraint, space, and type — not glow or chrome.
4. **Show the terminal player**: use current CLI/TUI examples so visitors know what they will install.
5. **Close with clarity** — downloads and help at the end, when the belief is set.

## Accessibility & Inclusion

WCAG AA throughout: contrast, keyboard access, focus visibility, and full respect for `prefers-reduced-motion`.
