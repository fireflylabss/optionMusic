# optionMusic — website

Standalone landing site (Vite + React + TS + Tailwind v4). Quiet B&W editorial.

- Home and trust-anchor pages are generated from a single content source (`src/content.ts`) into both HTML and Markdown variants.
- A Vercel Edge Middleware (`middleware.ts`) handles `Accept: text/markdown` content negotiation, real 404s, and `Vary: Accept, Accept-Encoding` headers.
- Static pages, `llms.txt`, `sitemap.xml`, and `robots.txt` are generated by `scripts/generate.ts` before each build.

## Commands

```bash
cd website
bun install
bun run dev       # generate and run Vite dev server on http://localhost:1421
bun run build     # typecheck, generate, and build dist/
bun run test      # build and run tests
bun run preview   # preview dist on :1421
bun run scripts/verify.ts   # local verification server that mimics the Vercel middleware
```

## Generated files

`index.html`, `public/*.html`, `public/*.md`, `llms.txt`, `sitemap.xml`, and `robots.txt` are generated from `src/content.ts`. Do not edit them by hand; run `bun run generate` after changing the content source.
