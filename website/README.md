# optionMusic — website

Standalone landing site (Vite + React + TS + Tailwind v4). Quiet B&W editorial, PT-BR.

Desktop app lives at repo root (`src-ui/`, port 1420) and is untouched.

## Commands

```bash
cd website
bun install
bun run dev      # http://localhost:1421
bun run build    # dist/
bun run preview  # preview dist on :1421
```
